This is an Ecommerce project for NTV school in Iceland. My own shop! 

Vercel link: https://lokaverkefni3.vercel.app/

Come buy some trash! There's Organic, Paper, Plastic, and Generic trash!

You can signup and login to add to cart, buy and (fake) checkout items. You can also browse items, search for them and control item quantity in chart.

This was made using React+Vite, Typescript, Tailwind CSS, Zustand, Cypress, and Shadcn for UI.

<b>Setup</b>
1. 'npm i' 
2. Copy `.env.example` to `.env` and fill in Supabase credentials
3. `npm run dev`

<b>Testing</b>
------
Cypress is used for testing. 
'npx cypress open' to open and test.
